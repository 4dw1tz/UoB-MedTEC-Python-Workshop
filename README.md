# Intro to Medical Python Workshop

A 50-minute beginner workshop designed for medical students who have never written a line of code.

## Why this exists

Medical professionals are increasingly expected to understand data, interpret algorithmic outputs, and engage with digital health tools. Yet most medical curricula don't include any programming education.

This workshop is a small step towards changing that. It introduces Python through a practical lens that feels relevant to medicine, rather than abstract computer science concepts.

## What students build

By the end of the session, students will have built a working BMI Calculator that takes patient information, computes BMI, and provides health category advice. It's simple, but it's theirs.

## Contents

- `instructor_copy.ipynb` - Full version with teaching notes, timing guidance, and solutions
- `student_workbook.ipynb` - Hands-on version with exercises and blanks to fill in

## How to run the workshop

Students don't need to install anything. Share this link and they can work directly in their browser:

```
https://colab.research.google.com/github/4dw1tz/UoB-MedTEC-Python-Workshop/blob/BAMSoc/student_workbook.ipynb
```

They'll need a Google account to save their own copy.

## Topics covered

- Printing output
- Variables and storing data
- Basic arithmetic and the BMI formula
- Getting user input
- Conditional logic with if/elif/else
